# Fragmentos exactos para impartir el taller

Estas marcas proceden de las narraciones finales; los fragmentos comienzan y terminan entre pasos. En la biblioteca, selecciona el episodio y pulsa el primer paso. Detén el video antes del paso siguiente al rango indicado. También puedes utilizar los controles del MP4.

Los fragmentos forman parte de los bloques de la agenda de **120 minutos**. El facilitador puede omitir alguno cuando el grupo necesite más tiempo de práctica. La serie completa queda como preparación y repaso.

| Bloque del taller | Episodio y pasos | Reproducir | Actividad inmediata |
|---|---|---|---|
| 00–10 | [01 · pasos 2–3](index.html#episode-01) | 0:32 → 1:42 (70 s) | Dibujar el recorrido y nombrar la fuente de cada dato. |
| 10–25 | [12 · pasos 2–3](index.html#episode-12) | 0:35 → 1:48 (73 s) | Completar el contexto y acordar las expectativas antes de generar código. |
| 25–45 | [05 · pasos 2–4](index.html#episode-05) | 0:35 → 2:26 (111 s) | Relacionar fixture, cliente HTTP y sesión del navegador. |
| 70–85 | [07 · pasos 4–6](index.html#episode-07) | 1:42 → 3:30 (108 s) | Simular 503, observar la UI y comprobar cero efectos reales. |
| 85–100 | [08 · pasos 4–6](index.html#episode-08) | 1:43 → 3:31 (107 s) | Relacionar solicitud, referencia, saldo y defecto de idempotencia. |
| 100–112 | [08 · pasos 9–10](index.html#episode-08) | 4:45 → 5:59 (74 s) | Revisar preparación del entorno y conservar artefactos al fallar. |
| 112–120 | [12 · pasos 11–11](index.html#episode-12) | 6:14 → 6:53 (38 s) | Aplicar la rúbrica al código y a la evidencia del participante. |

Tiempo audiovisual combinado: **9:41 aproximadamente**. Las marcas se muestran al segundo; las duraciones originales conservan milisegundos en `audio/NN/timeline.json`. El resto del taller se dedica a explicación, ejercicios, diagnóstico, evaluación y la pausa de cinco minutos.

Durante 45–65 minutos, cada participante consulta el episodio de su lenguaje (02, 03 o 04) solo si necesita resolver un paso. No se reproduce el episodio completo para todo el grupo.
